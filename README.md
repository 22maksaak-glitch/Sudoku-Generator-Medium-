# 🧩 Sudoku Generator (Medium) — головоломки для опытных игроков

> «Средний уровень — вызов для тех, кто уже освоил основы»

**Sudoku Generator (Medium)** — это набор консольных утилит для генерации головоломок судоку уровня «средний».  
Программа создаёт полностью решённое поле, а затем удаляет достаточное количество цифр (~45-50 пустых клеток), чтобы получилась играбельная головоломка с единственным решением.

## 🚀 Особенности
- 🎲 Генерация валидного решённого поля судоку.
- 🔢 Удаление цифр для создания головоломки (средний уровень: ~45-50 пустых клеток).
- ✅ Проверка уникальности решения (где реализовано).
- 🖥️ Вывод в терминал в виде красивой таблицы.
- 💾 Экспорт в текстовый, CSV, JSON и HTML формат.
- 🎨 Цветной вывод в терминале.
- 📐 Настройка размера (стандартное 9×9).
- 🧠 Возможность показать решение (опционально).
- 🔄 Поддержка seed для воспроизводимости.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python sudoku_generator.py`            |
| Go         | стандартная библиотека               | `go run sudoku_generator.go`            |
| JavaScript | Node.js, никаких                     | `node sudoku_generator.js`              |
| Java       | стандартная библиотека               | `javac sudoku_generator.java && java sudoku_generator` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand` (для перемешивания)           | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby sudoku_generator.rb`              |
| PHP        | стандартная библиотека               | `php sudoku_generator.php`              |
